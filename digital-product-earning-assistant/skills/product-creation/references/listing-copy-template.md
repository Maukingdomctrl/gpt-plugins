# Listing copy template

Write for a US parent, teacher or homeschooler deciding in 10 seconds. Use plain, specific, honest wording.

## Title (front-load what the buyer searches)
Pattern: `[Grade] [Topic] [Product type] | [Key feature] | [Format]`
Example: `Grade 3 Multiplication and Division Facts Worksheets | Word Problems + Answer Key | Printable PDF`
Check each platform's title length limit before finalising; don't stuff in repeated keywords.

## Description
1. **One-line promise:** who it is for and what they practise.
2. **What's included:** page counts per part, answer key, paper sizes (US Letter + A4), file type.
3. **How to use:** classwork, homework, morning work, review, homeschool.
4. **Skills covered:** in plain words. Name a standard (e.g. Common Core 3.OA) only if you checked that the content matches it.
5. **Important:** "This is a digital download. No physical item will be shipped. Print at home or at school."
6. **Terms of use:** personal or single-classroom use; no resale or redistribution.
Never write claims like "guaranteed to raise grades" or "best-selling".

## Tags / keywords (use every slot the platform allows; check its current limit)
- Mix topic + grade + format + use: `3rd grade math`, `multiplication worksheets`, `division facts`, `math word problems`, `printable worksheets`, `homeschool math`, `answer key included`.
- Use the buyer's words (US spelling: "math", "practice", "color").
- If you can browse, check which phrases appear in titles of comparable listings. If you can't, say the tags are unvalidated guesses.

## Images (in order)
1. Cover (square, 2000 px), showing title, grade, page count and paper size.
2. Watermarked preview of page 1.
3. Watermarked preview of a different part (e.g. the word problems).
4. Optional: answer-key preview (partly blurred or cropped).

## Pricing note
Suggest a test price only after the fee maths from the marketplace-research skill. Label it an experiment, not a forecast.
